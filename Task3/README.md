# Индексация базы знаний в FAISS

Этот скрипт подготавливает локальную векторную базу знаний для системы поиска по документам или RAG-приложения.

RAG, или Retrieval-Augmented Generation, представляет собой подход, при котором языковая модель сначала получает релевантные фрагменты из базы знаний, а затем формирует ответ с опорой на найденную информацию.

Скрипт выполняет следующие действия:

1. Загружает текстовые документы из базы знаний.
2. Разделяет документы на небольшие фрагменты, или чанки.
3. Преобразует чанки в векторные представления.
4. Создаёт поисковый индекс FAISS.
5. Сохраняет индекс.
6. Выполняет тестовый поиск по созданному индексу.

## Используемая модель

Для создания векторных представлений используется модель sentence-transformers/all-MiniLM-L6-v2

Модель загружается через библиотеку `Hugging Face` и используется с помощью класса `HuggingFaceEmbeddings` из пакета `langchain-huggingface`.

Основные характеристики:

- размерность вектора: 384;
- устройство выполнения: CPU;
- нормализация векторов включена;
- модель предназначена для семантического сравнения предложений и небольших фрагментов текста.

Нормализация векторов выполняется с помощью параметра:

```python
encode_kwargs={"normalize_embeddings": True}
```

После нормализации документы с похожим смыслом располагаются ближе друг к другу в векторном пространстве.

## База знаний

В качестве базы знаний используется каталог ../knowledge_base

Для каждого документа сохраняются метаданные:

| Поле                | Содержание                                        |
|---------------------|---------------------------------------------------|
| `source`            | Путь к исходному файлу                            |
| `title`             | Название файла без расширения                     |
| `document_id`       | Относительный путь к документу внутри базы знаний |
| `chunk_id`          | Глобальный идентификатор чанка                    |
| `chunk_in_document` | Порядковый номер чанка внутри документа           |

Метаданные позволяют определить, из какого документа и какого фрагмента был получен результат поиска.

## Разделение документов на чанки

Документы разделяются с помощью `RecursiveCharacterTextSplitter`.

Размер одного чанка 220 токенов
Перекрытие соседних чанков 30 токенов
Перекрытие необходимо для того, чтобы информация на границе двух фрагментов не теряла контекст.
Для подсчёта токенов используется токенизатор той же модели, которая создаёт эмбеддинги:

```python
AutoTokenizer.from_pretrained(
    "sentence-transformers/all-MiniLM-L6-v2"
)
```

Разделитель старается сохранить смысловую структуру текста. Сначала учитываются абзацы и строки, затем предложения, части предложений и отдельные слова.


## Векторный индекс

Для хранения векторных представлений используется FAISS.

FAISS, или Facebook AI Similarity Search, представляет собой библиотеку для быстрого поиска ближайших векторов.

Индекс сохраняется в каталог ../faiss_index

После успешного выполнения в этом каталоге обычно создаются файлы:

```text
index.faiss
index.pkl
```

Файл `index.faiss` содержит векторный индекс, а `index.pkl` содержит документы и связанные с ними метаданные.

## Количество чанков

Количество чанков зависит от:

- числа документов в базе знаний;
- объёма документов;
- структуры текста;
- размера чанка;
- величины перекрытия.

## Время генерации индекса

Время измеряется для этапов:

1. создания векторных представлений чанков;
2. формирования индекса FAISS.

Измерение начинается перед выполнением:

```python
vectorstore = FAISS.from_documents(chunks, embeddings)
```

и заканчивается после создания индекса.

Время загрузки документов, разделения текста на чанки и сохранения индекса в данный показатель не включено полностью.

Фактическое время зависит от:

- количества и размера документов;
- количества сформированных чанков;
- производительности процессора;
- объёма доступной оперативной памяти;
- наличия модели в локальном кэше Hugging Face.

При первом запуске выполнение может занять больше времени, поскольку модель и токенизатор загружаются из Hugging Face.

## Требования

Основные зависимости:

```text
langchain-community
langchain-huggingface
langchain-text-splitters
sentence-transformers
transformers
faiss-cpu
```

Установить зависимости можно следующей командой:

```bash
pip install langchain-community langchain-huggingface langchain-text-splitters sentence-transformers transformers faiss-cpu
```

## Запуск

```bash
python build_index.py
```

## Тестирование поиска

После создания индекса скрипт автоматически выполняет тестовый запрос:

```text
Who is Kaelen Starfire?
```

Поиск возвращает три наиболее близких чанка:

```python
vectorstore.similarity_search_with_score(test_query, k=3)
```

Для каждого результата выводятся:

- позиция в выдаче;
- расстояние между запросом и чанком;
- путь к исходному документу;
- идентификатор чанка;
- первые 500 символов найденного текста.
